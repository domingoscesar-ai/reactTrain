# Todo List

Aplicação para praticar gerenciamento de estado, listas dinâmicas e interação com o usuário em React.

## Objetivo

Construir uma lista de tarefas funcional, com criação, marcação e remoção de itens, reforçando conceitos de estados e componentes reutilizáveis.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Funcionalidades esperadas

- Adicionar tarefas
- Marcar como concluída
- Remover itens
- Filtrar tarefas
- Exibir contador de itens pendentes

## Como executar

```bash
npm install
npm run dev
```

Este projeto é uma excelente prática para o uso de hooks, eventos e renderização condicional.
