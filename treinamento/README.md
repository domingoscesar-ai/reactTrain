# Treinamento

Projeto de estudo criado para reforçar conceitos de componentes, estruturação de código e interfaces em React.

## Objetivo

Servir como ambiente de prática para explorar reutilização de componentes, organização de layouts e desenvolvimento de interfaces mais completas.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Foco de aprendizado

- Estrutura de componentes
- Estilização visual
- Organização de arquivos
- Experiência do usuário
- Prática com hooks e state

## Como executar

```bash
npm install
npm run dev
```

Este projeto funciona como uma base para pequenas implementações e testes de conceitos front-end.
