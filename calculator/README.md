# Calculadora

Projeto de treinamento criado para praticar lógica de programação, manipulação de estado e interfaces interativas em React com TypeScript.

## Objetivo

Desenvolver uma calculadora funcional com operações básicas, foco em eventos de clique, estados e organização da interface.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Funcionalidades esperadas

- Entrada de números e operadores
- Cálculo de operações básicas
- Limpeza de dados
- Exibição de resultado em tempo real
- Interface simples e responsiva

## Como executar

```bash
npm install
npm run dev
```

Este projeto serve como base para praticar desenvolvimento de componentes e lógica de UI em aplicações front-end.
