# Weather

Projeto de treinamento voltado para estudo de interfaces de clima, consumo de dados e renderização condicional em React.

## Objetivo

Praticar a construção de uma aplicação para exibir informações climáticas de forma clara e responsiva, com foco em estado, componentes e apresentação dinâmica de dados.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Funcionalidades esperadas

- Busca por cidade
- Exibição de temperatura
- Status do clima
- Condições do ambiente
- Layout visual amigável e responsivo

## Como executar

```bash
npm install
npm run dev
```

Este projeto é ideal para praticar desenvolvimento de componentes de dados e UX em aplicações front-end.
