# React Training

Repositório de aprendizagem focado em desenvolvimento front-end com React, TypeScript e Vite. Este projeto reúne uma coleção de mini-aplicações criadas para praticar conceitos fundamentais de interface, estado, componentes, lógica e experiência do usuário.

## Objetivo

O objetivo principal deste repositório é consolidar habilidades práticas em React e TypeScript por meio de projetos pequenos, objetivos e bem definidos. Cada aplicação funciona como uma etapa de treinamento para explorar diferentes cenários de desenvolvimento web moderno.

## Stack tecnológica

- React
- TypeScript
- Vite
- CSS
- HTML
- JavaScript moderno

## Estrutura do repositório

- `calculator` — calculadora interativa para praticar lógica de operações e manipulação de estado.
- `cronometroLapTimer` — cronômetro com marcação de voltas para treinar temporizadores e eventos.
- `galeria` — galeria de imagens para explorar layout, listas e renderização dinâmica.
- `TodoList` — lista de tarefas para trabalhar com gerenciamento de estado e interação do usuário.
- `treinamento` — projeto de estudo focado em interfaces e componentes reutilizáveis.
- `weather` — aplicação de clima para exercitar consumo de dados e renderização condicional.

## Visão geral dos projetos

Cada pasta representa um mini-projeto independente, inicializado com Vite e preparado para evoluir conforme os conceitos forem sendo aprendidos. A arquitetura é simples e modular, favorecendo a prática de estruturação de componentes, estilos e controle de estado.

## Como executar

Pré-requisitos:

- Node.js 18+
- npm ou yarn

Passo a passo:

1. Acesse a pasta do projeto desejado.
2. Instale as dependências:

```bash
npm install
```

3. Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

4. Abra a URL indicada no terminal para visualizar a aplicação.

## Fluxo de aprendizagem sugerido

1. Iniciar com projetos mais simples, como calculadora e lista de tarefas.
2. Avançar para temporizadores, galerias e componentes visuais.
3. Explorar integração com APIs e dados dinâmicos em projetos como clima.
4. Consolidar boas práticas de organização de código, componentização e UX.

## Boas práticas aplicadas

- Componentização em React
- Tipagem com TypeScript
- Organização por pastas e responsabilidades
- Uso de hooks para estados e interações
- Estilos encapsulados por arquivo CSS
- Desenvolvimento de interfaces responsivas
