# Galeria

Projeto voltado ao estudo de layouts, listas e renderização dinâmica em React.

## Objetivo

Praticar a criação de uma galeria visual com imagens, cards e organização em grade, reforçando a estrutura de componentes e a apresentação responsiva.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Funcionalidades esperadas

- Exibição de imagens em grid
- Listagem dinâmica de itens
- Layout responsivo
- Cards com títulos e descrições
- Possibilidade de expansão ou seleção de imagens

## Como executar

```bash
npm install
npm run dev
```

Este projeto ajuda a desenvolver habilidades em composição visual, renderização de listas e responsividade em interfaces front-end.
