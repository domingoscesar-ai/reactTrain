# Cronômetro com marcação de voltas

Aplicação desenvolvida para praticar temporizadores, intervalos e controle de eventos em React.

## Objetivo

Criar um cronômetro com funcionalidades de início, pausa, reinício e registro de voltas, exercitando manipulação de tempo e estados assíncronos.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Funcionalidades esperadas

- Iniciar e pausar o cronômetro
- Registrar tempos de volta
- Reiniciar contagem
- Exibir lap time em tempo real
- Interface clara para uso em treinamento esportivo ou de produtividade

## Como executar

```bash
npm install
npm run dev
```

Este projeto é ideal para exercitar hooks de estado, timers e lógica reativa.
